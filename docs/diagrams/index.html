prompt-library, in three diagrams

All three are traced from the plugin's source; file paths are in the tooltips and table views. Use cases keep the same colour in every diagram.

1 · Control flow (Sankey) 2 · Use-case decomposition (circle packing) 3 · Data model (sunburst)

1 · How each use case flows through the plugin

Entry point → adapter → service method → component → storage. Band width counts distinct call paths, so a use case that touches more of the system is wider. Hover a band or node for its file; click a use case to isolate it.

  • Every service is built by PromptLibraryService.open(), which also runs PromptRepository.initialize() (lock + create file with header). It happens once per process, not per use case, so it isn't drawn.
  • Writes re-read the CSV inside the lock, then replace the whole file atomically. That's why every write shows three storage paths.
  • Bulk import is only reachable from the CLI. There is no prompt_import MCP tool.
